Tracepie is a Rust project focused on a live code map and connected retrieval for coding agents. The planned model brings code, documentation, comments and authorized knowledge sources together while retaining their provenance.

## Find sources, then follow connections

An agent may begin with a name, a symptom or a requirement. Search discovers candidate sources. Inspection resolves a known target and exposes its context. Map and trace operations reveal inventories, structure and directed relationships.

Connections need a stated basis. A direct call, a reference, a candidate dispatch and a semantic connection convey different kinds of evidence.

## Keep the evidence visible

The design calls for source identities, revisions, coverage and freshness to accompany results. Missing capabilities and incomplete work must remain visible so an agent can judge what a result establishes.
