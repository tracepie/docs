Tracepie is being developed to connect code, documentation, comments and evidence in a versioned map. It is designed to help coding agents find relevant sources, follow relationships and explain what supports an answer.

**Tracepie is in development.** These pages introduce the intended model and tool interface. They are not release documentation or evidence that an API is available.

[Read the documentation](@/docs/_index.md).

## From a question to its evidence

Search discovers what to inspect. The map exposes what is connected. Analysis calculates structural properties. The agent interprets the evidence and performs the work.

Start with [the overview](@/docs/overview.md), then learn [when to use each tool](@/docs/tools.md).
